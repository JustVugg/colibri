# The two fields a reader is meant to compare:
#   packed: kv mirror 13.1 MiB (quantized) | host kv 16.8 MiB (packed)
#   fp32:   kv mirror 51.6 MiB             | (no 'host kv' field: the host rows are f32)
# The 'kv mirror' size differs because the packed arm stores the mirrors as the
# checkpoint's cache codes (528 B a window row, 288 B a compressed row); the fp32

#   890*16384 + 3,032,832 = 17,614,592 B = 16.8 MiB (packed host KV)
#   6400*16384 + 11,763,712 = 116,621,312 B (fp32 host KV, not printed as 'host kv')
