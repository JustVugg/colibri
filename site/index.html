03 / How the engine works

One hierarchy.
Your hardware.

Colibri treats GPU memory, system RAM and storage as one hierarchy. It adapts where model weights live and how they are executed to the resources available on your machine.

Weights can stay in memory when capacity allows, or stream from storage when needed. CPU and GPU execution work with the hardware and backends available.

Install Colibri.
Run your first model.

A DOUBLE CLICK TO BEGIN

Download. Unzip. Start.

  1. Open the project and choose Code → Download ZIP.
  2. Unzip the folder and run START-HERE.bat.
  3. Follow the setup for your model and machine.
